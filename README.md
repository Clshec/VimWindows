## ✨ المميزات الرئيسية (Key Features)

- 🟢 **نظام الوضعين (Modal Architecture)**: تفعيل وفصل فوري بين وضع الملاحة (**NORMAL MODE**) ووضع الكتابة العادي (**INSERT MODE**) بالضغط على `Ctrl + Win`.
- 🌊 **تمرير تلقائي انسيابي فائق النعومة (60 FPS Smooth Auto-Scroll)**: محرك بكسلي ميكروي (High-Resolution Sub-Delta) بتردد 60 إطار في الثانية لانزلاق هادئ وسلس كشاشات اللمس.
- ⚡ **تحكم متدرج بالسرعة (10 مستويات)**: تدرج سرعات هادئ ومريح جداً للقراءة، يبدأ من نبضة فائقة البطء (`0.5 Delta`)، مع تحكم فوري بأزرار `+` و `-`.
- 📊 **مؤشر مرئي ذكي (Dynamic ToolTip)**: شريط بياني عائم يوضح الوضع، والاتجاه، والسرعة اللحظية `[███░░░░░░░] 3/10`.
- 🛡️ **عزل متصفح Chrome تلقائياً**: تعطيل السكريبت تلقائياً داخل Google Chrome لتفادي التعارض مع إضافة Vimium الأصلية.
- ⚡ **تنقل وتفاعل شامل في النظام**: التحكم في التبويبات، والوسائط، والتاريخ، والبحث بلوحة المفاتيح فقط.

## 🚀 طريقة التثبيت والتشغيل (Installation & Setup)

1. تأكد من تثبيت **[AutoHotkey v2](https://www.autohotkey.com/)** على جهازك.
2. قم بتحميل أو استنساخ هذا المستودع:
   ```bash
   git clone https://github.com/Clshec/VimWindows.git
   ```
3. شغّل السكريبت بإحدى الطرق التالية:
   - **طريقة النقرة الواحدة**: اضغط نقراً مزدوجاً على الملف المشغل [`Start_VimWindows.bat`](Start_VimWindows.bat).
   - **التشغيل المباشر**: اضغط نقراً مزدوجاً على ملف [`vim_windows.ahk`](vim_windows.ahk).
4. اضغط على **`Ctrl + Win`** للدخول إلى `🟢 NORMAL MODE` وابدأ استخدام الاختصارات!

## ⌨️ جدول الاختصارات الكامل (Shortcuts Cheat Sheet)

> [!NOTE]
> جميع الاختصارات أدناه تعمل عند تفعيل **NORMAL MODE** (عبر الضغط على `Ctrl + Win`).  
> للخروج إلى وضع الكتابة العادي، اضغط **`Esc`** أو **`i`**.

### 1. التمرير التلقائي الانسيابي (Smooth Auto-Scroll)

| الاختصار | التأثير | الوصف |
| :--- | :--- | :--- |
| **`v`** أو **`Ctrl + j`** أو **`Space`** | ⏬ **تمرير تلقائي لأسفل** | يبدأ الانزلاق البكسلي المستمر لأسفل (60 FPS). |
| **`V`** (`Shift + v`) أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | يبدأ الانزلاق البكسلي المستمر لأعلى (60 FPS). |
| **`=`** أو **`+`** أو **`Numpad +`** | ⚡ **تسريع التمرير** | رفع سرعة الانزلاق بمقدار درجة واحدة (من 1 إلى 10). |
| **`-`** أو **`Numpad -`** | 🐌 **تبطئة التمرير** | خفض سرعة الانزلاق بمقدار درجة واحدة. |
| **`Space`** أو **`Esc`** أو **`i`** أو أي زر تنقل | ⏹️ **إيقاف التمرير** | إيقاف التمرير التلقائي فوراً في أي لحظة. |

## 🔄 التشغيل التلقائي مع بدء ويندوز (Run on Windows Startup)

لجعل السكريبت يعمل تلقائياً عند تشغيل الكمبيوتر:
1. اضغط على **`Win + R`** في لوحة المفاتيح لفتح نافذة Run.
2. اكتب الأمر التالي واضغط Enter:
   ```text
   shell:startup
   ```
3. قم بإنشاء اختصار (Shortcut) لملف [`Start_VimWindows.bat`](Start_VimWindows.bat) أو [`vim_windows.ahk`](vim_windows.ahk) وضعه داخل هذا المجلد.
