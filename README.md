## 🏗️ المعمارية الموحدة للمشروع (Unified Architecture)

يعتمد مشروع **VimWindows** على تصميم نقي ومباشر 100% بدون أي اعتمادات أو برامج خارجية معقدة:

```text
VimWindows (المنظومة الموحدة)
│
├── 🌐 تبديل اللغة الفوري (CapsLock Language Switcher - عربي ↔ إنجليزي)
│
└── 🟢 NORMAL MODE الموحد (يعمل بنقرة واحدة عبر زر Home)
    ├── 🖱️ محرك الماوس المباشر (WASD + Win32 API Hardware Polling)
    ├── 📜 ملاحة وتمرير Vimium الأصلي (HJKL, gg/G, d/u)
    ├── 🎯 محرك التلميحات الذكي (UI Hint Mode f/F)
    ├── 🔢 شبكة القفز السريع (3x3 Grid Jump g)
    └── 🌊 التمرير التلقائي الانسيابي (Target ~60 Hz Micro-Scroll)
```

---

## 🚀 التثبيت الذكي الموحد (1-Click Unified Installation)

1. قم بتحميل أو استنساخ المستودع:
   ```bash
   git clone https://github.com/Clshec/VimWindows.git
   ```
2. اضغط نقراً مزدوجاً على **[`install.bat`](install.bat)**.
3. يقوم المثبت الذكي بالآتي تلقائياً:
   - فحص وتثبيت **AutoHotkey v2** تلقائياً في حال عدم وجوده.
   - ضبط الإعدادات وإضافة المنظومة لبدء التشغيل مع ويندوز (`shell:startup`).
   - تشغيل السكريبت الموحد في الخلفية بأمان واستقرار تام.

## ⌨️ جدول الاختصارات الشامل (Complete Shortcuts Cheat Sheet)

> [!TIP]
> **تبديل لغة الإدخال الفوري (CapsLock Language Switcher)**:  
> - **ضغطة واحدة على `CapsLock`**: تبديل فوري بين اللغات (عربي ↔ إنجليزي) بدون الحاجة لـ `Alt+Shift`.  
> - **`Shift + CapsLock`**: تشغيل / إيقاف وضع الحروف الكبيرة (Caps Lock الأصلي).

> [!NOTE]
> **زر `Home`** (أو `NumpadHome` أو `Ctrl+Win`) هو المفتاح الموحد للتنقل بنقرة واحدة:  
> - **ضغطة واحدة**: 🟢 **NORMAL MODE** (شارة خضراء كبيرة - ماوس WASD + ملاحة Vimium وتمرير وتلميحات).  
> - **`Esc` أو `i` أو `Home`**: ⚫ **INSERT MODE** (وضع الكتابة العادي في ويندوز).

### 1. تحكم الماوس المباشر عبر WASD

| الاختصار | الوظيفة | الوصف |
| :--- | :--- | :--- |
| **`W / A / S / D`** أو **الأسهم** | 🖱️ **تحريك الماوس** | تحريك ناعم وفوري وتسارع فيزيائي عالي جداً بدون تأخير. |
| **`Space`** أو **`Enter`** | 👈 **نقر أيسر** | Left Click مباشر في مكان المؤشر الحالي. |
| **`Shift + Space`** أو **`r`** | 👉 **نقر أيمن** | Right Click لفتح القائمة السياقية (Context Menu). |
| **`e`** أو **`Ctrl + Space`** | 🔘 **نقر أوسط** | Middle Click لفتح الروابط في تبويب جديد. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة البطيء** | إبطاء الحركة للتحكم الدقيق بالبكسل الواحد. |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو السريع** | مضاعفة السرعة (2.5x) للقفز بين الشاشات المتعددة. |
| **`v`** | ✊ **وضع السحب والإفلات (Drag)** | تثبيت زر الفأرة مضغوطاً لتحديد النصوص وسحب النوافذ. |
| **`g`** | 🔢 **شبكة القفز 3x3** | إظهار شبكة القفز الفوري للشاشة (1 إلى 9) أو `gg` لأعلى الصفحة. |

---

### 2. وضع التلميحات التفاعلي (Interactive Hint Mode - `f`)

| الاختصار | الوظيفة | الوصف |
| :--- | :--- | :--- |
| **`f`** | 🎯 **إظهار تلميحات العناصر (Hint Mode)** | يظهر بطاقات تلميح صفراء فوق عناصر وأزرار النافذة؛ اكتب الحرف للنقر بزر الماوس الأيسر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **نقر بزر الماوس الأيمن** | يظهر التلميحات وينقر بزر الماوس الأيمن على العنصر المحدد. |

---

### 3. شبكة القفز السريع 3x3 (Grid Jump - `g`)

| الاختصار | الوظيفة | الوصف |
| :--- | :--- | :--- |
| **`g`** | 🔢 **إظهار شبكة القفز 3x3** | تظهر شبكة مرقمة من 1 إلى 9 على الشاشة؛ اضغط الرقم للقفز الفوري للمنطقة. |
| **`gg`** | 🔝 **أعلى الصفحة** | ضغط `g` مرتين متتاليتين ينقلك لبداية الصفحة أو المستند (`Ctrl + Home`). |
| **`G`** (`Shift + g`) | 🔚 **أسفل الصفحة** | انتقال فوري لنهاية المستند أو الصفحة (`Ctrl + End`). |

### 4. التمرير التلقائي الانسيابي (Smooth Auto-Scroll)

| الاختصار | الوظيفة | الوصف |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** | ⚡ **زيادة السرعة** | تسريع التمرير التلقائي (مستويات من 1 إلى 10). |
| **`-`** | 🐌 **تقليل السرعة** | إبطاء التمرير التلقائي. |
