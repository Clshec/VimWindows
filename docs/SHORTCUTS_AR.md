# 📖 دليل الاختصارات الشامل - VimWindows (باللغة العربية)

مرحباً بك في الدليل التفصيلي لاختصارات **VimWindows**. المنظومة الموحدة النقية تمنحك تحكماً شاملاً وسريعاً بنظام ويندوز مع وضع ملاحة وماوس مدمج بنقرة واحدة عبر زر **`Home`** وتبديل فوري للغة الإدخال عبر زر **`CapsLock`**.

---

## 🌐 تبديل لغة الإدخال الفوري (CapsLock Language Switcher)

| الاختصار | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`CapsLock`** | 🌐 **تبديل اللغة (عربي ↔ إنجليزي)** | ضغطة واحدة سريعة على زر CapsLock تبدل لغة الإدخال فوراً بنمط Mac والمحترفين. |
| **`Shift + CapsLock`** | 🔠 **تفعيل / تعطيل الحروف الكبيرة** | تشغيل أو إيقاف وضع الحروف الكبيرة (Caps Lock الأصلي). |

---

## 🎯 تفعيل وضع الملاحة الموحد (NORMAL MODE)

زر **`Home`** (أو `NumpadHome` أو `Ctrl + Win`) هو المفتاح الموحد للتنقل بنقرة واحدة:

```text
               ┌─────────────────────────────────────────┐
               │         ⚫ INSERT MODE (الكتابة)        │
               └────────────────────┬────────────────────┘
                                    │ اضغط Home (أو Ctrl+Win)
                                    ▼
               ┌─────────────────────────────────────────┐
               │         🟢 NORMAL MODE الموحد           │
               │ (ماوس WASD + تمرير HJKL + تلميحات f)   │
               └────────────────────┬────────────────────┘
                                    │ اضغط Esc أو i أو Home
                                    ▼
               ┌─────────────────────────────────────────┐
               │         ⚫ INSERT MODE (الكتابة)        │
               └─────────────────────────────────────────┘
```

- **تفعيل الوضع**: اضغط **`Home`** لتظهر الشارة الخضراء الكبيرة **`🟢 NORMAL MODE`** في أعلى الشاشة.
- **إيقاف الوضع**: اضغط **`Esc`** أو **`i`** أو **`Home`** للعودة الفورية للكتابة العادية.

## 🖱️ 1. تحكم الماوس المباشر عبر WASD (في وضع NORMAL MODE)

| الزر | الاتجاه / الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`W`** أو **`↑`** | ⬆️ **أعلى** | تحريك مؤشر الفأرة للأعلى بسرعة فائقة وتسارع فيزيائي سلس. |
| **`A`** أو **`←`** | ⬅️ **يسار** | تحريك مؤشر الفأرة لليسار. |
| **`S`** أو **`↓`** | ⬇️ **أسفل** | تحريك مؤشر الفأرة للأسفل. |
| **`D`** أو **`→`** | ➡️ **يمين** | تحريك مؤشر الفأرة لليمين. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة بالبكسل** | إبطاء الحركة للتحكم الدقيق بالبكسل الواحد للنقر المتناهي الدقة. |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو الخارق** | مضاعفة السرعة 2.5x للقفز اللحظي بين الشاشات المتعددة. |
| **`Space`** أو **`Enter`** | 👈 **نقر أيسر (Left Click)** | نقرة ماوس يسارية عادية في موقع المؤشر. |
| **`Shift + Space`** أو **`r`** | 👉 **نقر أيمن (Right Click)** | فتح القائمة السياقية (Context Menu). |
| **`e`** أو **`Ctrl + Space`** | 🔘 **نقر أوسط (Middle Click)** | فتح الروابط في تبويب جديد. |
| **`v`** | ✊ **السحب والإفلات (Drag Mode)** | تثبيت زر الفأرة مضغوطاً لسحب النوافذ وتحديد النصوص؛ اضغط `v` للإفلات. |
| **`g`** | 🔢 **شبكة القفز 3x3** | إظهار شبكة القفز الفوري للشاشة واختيار رقم من 1 إلى 9 (أو `gg` لأعلى الصفحة). |

## 🧭 2. التمرير والملاحة الأصلية بنمط Vimium (HJKL)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`j`** | ⬇️ تمرير لأسفل | تمرير خطوتين للأسفل في المستند أو الصفحة. |
| **`k`** | ⬆️ تمرير لأعلى | تمرير خطوتين للأعلى. |
| **`h`** | ⬅️ تنقل لليسار | حركة لليسار بأمان تام. |
| **`l`** | ➡️ تنقل لليمين | حركة لليمين بأمان تام. |
| **`Shift + d`** | ⏬ نصف صفحة لأسفل | تمرير سريع بمقدار نصف شاشة. |
| **`u`** | ⏫ نصف صفحة لأعلى | تمرير سريع بمقدار نصف شاشة. |
| **`gg`** | 🔝 قمة الصفحة | انتقال فوري لبداية المستند أو الصفحة (`Ctrl + Home`). |
| **`G`** (`Shift + g`) | 🔚 نهاية الصفحة | انتقال فوري لنهاية المستند أو الصفحة (`Ctrl + End`). |

## 🎯 3. وضع التلميحات الذكي (UI Hint Mode - `f`)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`f`** | 🎯 **تلميحات ونقر أيسر** | تظهر حروف صفراء فوق الأزرار والروابط؛ اكتب الحرف للنقر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **تلميحات ونقر أيمن** | إظهار التلميحات والنقر بزر الماوس الأيمن (Context Menu). |

## 🌊 4. التمرير التلقائي الانسيابي (~60 Hz Auto-Scroll)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** أو **`Numpad +`** | ⚡ **تسريع التمرير** | رفع سرعة التمرير (المستويات من 1 إلى 10). |
| **`-`** أو **`Numpad -`** | 🐌 **تبطئة التمرير** | خفض سرعة التمرير. |
