# 📖 دليل الاختصارات الشامل - VimWindows (باللغة العربية)

مرحباً بك في الدليل التفصيلي لاختصارات **VimWindows**. المنظومة الموحدة النقية تمنحك تحكماً شاملاً وسريعاً بنظام ويندوز مع وضع ملاحة وماوس متطابق ثنائي اليدين بنقرة واحدة عبر زر **`Home`** وتبديل فوري للغة الإدخال عبر زر **`CapsLock`**.

---

## 🌐 تبديل لغة الإدخال الفوري (CapsLock Language Switcher)

| الاختصار | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`CapsLock`** | 🌐 **تبديل اللغة (عربي ↔ إنجليزي)** | ضغطة واحدة سريعة على زر CapsLock تبدل لغة الإدخال فوراً بنمط Mac والمحترفين. |
| **`Shift + CapsLock`** | 🔠 **تفعيل / تعطيل الحروف الكبيرة** | تشغيل أو إيقاف وضع الحروف الكبيرة (Caps Lock الأصلي). |

---

## 🎯 تفعيل وضع الملاحة الموحد (NORMAL MODE)

زر **`Home`** (أو `NumpadHome` أو `Ctrl + Win`) هو المفتاح الموحد للتنقل بنقرة واحدة:

```text
               ┌─────────────────────────────────────────┐
               │         ⚫ INSERT MODE (الكتابة)        │
               └────────────────────┬────────────────────┘
                                    │ اضغط Home (أو Ctrl+Win)
                                    ▼
               ┌─────────────────────────────────────────┐
               │         🟢 NORMAL MODE الموحد           │
               │ (ماوس متطابق ثنائي اليدين + تمرير HJK)  │
               └────────────────────┬────────────────────┘
                                    │ اضغط Esc أو i أو Home
                                    ▼
               ┌─────────────────────────────────────────┐
               │         ⚫ INSERT MODE (الكتابة)        │
               └────────────────────┬────────────────────┘
```

## 🖐️ 1. تحكم الماوس المتطابق ثنائي اليدين (Symmetric Dual-Hand Mouse)

يمكنك التحكم بالماوس بحرية كاملة إما باليد اليسرى أو اليد اليمنى بجوار Enter:

### 🖐️ الجانب الأيسر (Left Hand - WASD + ZXC):
| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`W` / `A` / `S` / `D`** | 🖱️ **حركة الماوس** | أعلى / يسار / أسفل / يمين باستجابة فورية ونعومة تامة. |
| **`Z`** | 👈 **نقر أيسر (Left Click)** | نقر أيسر بالخنصر أو البنصر الأيسر. |
| **`X`** | 🔘 **نقر أوسط / بكرة (Middle Click)** | نقر أوسط لفتح الروابط في تبويب جديد. |
| **`C`** | 👉 **نقر أيمن (Right Click)** | فتح القائمة السياقية (Context Menu). |

### 🖐️ الجانب الأيمن (Right Hand - PL;' + ,./ بجوار Enter):
| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`P` / `L` / `;` / `'`** أو **الأسهم** | 🖱️ **حركة الماوس** | أعلى / يسار / أسفل / يمين بجوار زر Enter مباشرة. |
| **`,`** | 👈 **نقر أيسر (Left Click)** | نقر أيسر باليد اليمنى. |
| **`.`** | 🔘 **نقر أوسط / بكرة (Middle Click)** | نقر أوسط باليد اليمنى. |
| **`/`** | 👉 **نقر أيمن (Right Click)** | نقر أيمن باليد اليمنى. |

### ⚡ معدلات السرعة والإضافات:
| الاختصار | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **زرين معاً** (مثل `W+D` أو `P+'`) | 🚀 **سرعة توربو (50px)** | قفز سريع متوازن عبر الشاشة. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة بالبكسل** | إبطاء الحركة للتحكم الدقيق المتناهي (1.5 بكسل). |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو الإضافي** | مضاعفة السرعة للقفز بين الشاشات المتعددة. |
| **`v`** | ✊ **السحب والإفلات (Drag Mode)** | تثبيت زر الفأرة لسحب النوافذ وتحديد النصوص؛ اضغط `v` للإفلات. |
| **`g`** | 🔢 **شبكة القفز 3x3** | إظهار شبكة القفز الفوري للشاشة (1 إلى 9) أو `gg` لأعلى الصفحة. |

## 🧭 2. التمرير والملاحة بنمط Vimium (HJK)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`j`** | ⬇️ تمرير لأسفل | تمرير خطوتين للأسفل في المستند أو الصفحة. |
| **`k`** | ⬆️ تمرير لأعلى | تمرير خطوتين للأعلى. |
| **`h`** | ⬅️ تنقل لليسار | حركة لليسار بأمان تام. |
| **`Shift + d`** | ⏬ نصف صفحة لأسفل | تمرير سريع بمقدار نصف شاشة. |
| **`u`** | ⏫ نصف صفحة لأعلى | تمرير سريع بمقدار نصف شاشة. |
| **`gg`** | 🔝 قمة الصفحة | انتقال فوري لبداية المستند أو الصفحة (`Ctrl + Home`). |
| **`G`** (`Shift + g`) | 🔚 نهاية الصفحة | انتقال فوري لنهاية المستند أو الصفحة (`Ctrl + End`). |

## 🎯 3. وضع التلميحات الذكي (UI Hint Mode - `f`)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`f`** | 🎯 **تلميحات ونقر أيسر** | تظهر حروف صفراء فوق الأزرار والروابط؛ اكتب الحرف للنقر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **تلميحات ونقر أيمن** | إظهار التلميحات والنقر بزر الماوس الأيمن (Context Menu). |

## 🌊 4. التمرير التلقائي الانسيابي (~60 Hz Auto-Scroll)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** | ⚡ **تسريع التمرير** | رفع سرعة التمرير (المستويات من 1 إلى 10). |
| **`-`** | 🐌 **تبطئة التمرير** | خفض سرعة التمرير. |
