# 📖 دليل الاختصارات الشامل - VimWindows (باللغة العربية)

مرحباً بك في الدليل التفصيلي لاختصارات **VimWindows**. المنظومة تمنحك تحكماً شاملاً وسريعاً بنظام ويندوز مع دورة أوضاع ثلاثية ذكية عبر زر **`Home`** حصراً.

---

## 🎯 دورة الأوضاع الذكية عبر زر Home (3-State Mode Cycler)

زر **`Home`** هو المفتاح الموحد والوحيد للتنقل التتابعي السلس بين الأوضاع الثلاثة:

```text
               ┌─────────────────────────────────────────┐
               │         ⚫ 0. INSERT MODE (الكتابة)       │
               └────────────────────┬────────────────────┘
                                    │ ضغطة 1 على Home
                                    ▼
               ┌─────────────────────────────────────────┐
               │         🟢 1. NORMAL MODE (الملاحة)      │
               └────────────────────┬────────────────────┘
                                    │ ضغطة 2 على Home
                                    ▼
               ┌─────────────────────────────────────────┐
               │         🔵 2. MOUSE MODE (الماوس 10x)    │
               └────────────────────┬────────────────────┘
                                    │ ضغطة 3 على Home (أو Esc)
                                    ▼
               ┌─────────────────────────────────────────┐
               │         ⚫ 0. INSERT MODE (الكتابة)       │
               └─────────────────────────────────────────┘
```

- **ضغطة 1**: تفعيل `🟢 NORMAL MODE` (شارة خضراء كبيرة في أعلى الشاشة لملاحة Vimium والتمرير والتلميحات).
- **ضغطة 2**: تفعيل `🔵 MOUSE MODE` (شارة زرقاء كبيرة لتحريك الماوس بسرعة خارقة 10x والنقر).
- **ضغطة 3**: الرجوع إلى `⚫ INSERT MODE` (وضع الكتابة العادي في ويندوز).
- **زر `Esc`**: يخرجك فوراً من أي وضع إلى وضع الكتابة العادي `INSERT MODE`.

---

## 🖱️ 1. وضع الماوس الخارق (MOUSE MODE - الحالة 2 🔵)

عند الضغط للمرة الثانية على زر `Home`، تدخل في **وضع الماوس المستقل فائق السرعة والسلاسة (10x Boosted Physics Engine)**:

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`h / j / k / l`** أو **الأسهم** أو **`WASD`** أو **`UIOP`** | 🖱️ **تحريك الماوس بسرعة فائقة** | محرك إزاحة فورية مع تسارع فيزيائي ناعم وسرعة مضاعفة 10 مرات. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة بالبكسل** | إبطاء الحركة للتحكم الدقيق بالبكسل الواحد للنقر المتناهي الدقة. |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو الخارق** | مضاعفة السرعة 2.5x للقفز اللحظي بين الشاشات المتعددة. |
| **`Space`** أو **`Enter`** | 👈 **نقر أيسر (Left Click)** | نقرة ماوس يسارية عادية في موقع المؤشر. |
| **`Shift + Space`** أو **`Shift + Enter`** | 👉 **نقر أيمن (Right Click)** | فتح القائمة السياقية (Context Menu). |
| **`Ctrl + Space`** | 🔘 **نقر أوسط (Middle Click)** | فتح الروابط في تبويب جديد. |
| **`v`** | ✊ **السحب والإفلات (Drag Mode)** | تثبيت زر الفأرة مضغوطاً لسحب النوافذ وتحديد النصوص؛ اضغط `v` للإفلات. |
| **`g`** | 🔢 **شبكة القفز 3x3** | إظهار شبكة القفز الفوري للشاشة واختيار رقم من 1 إلى 9. |
| **`Esc`** | ❌ **خروج فوري** | الخروج إلى وضع الكتابة العادي. |

## 🧭 2. وضع الملاحة العام (NORMAL MODE - الحالة 1 🟢)

عند الضغط للمرة الأولى على زر `Home`، تعمل جميع اختصارات Vimium الأصلية بكامل كفاءتها:

### 📜 التمرير والتنقل بالصفحات:
| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`j`** | ⬇️ تمرير لأسفل | تمرير خطوتين للأسفل في المستند أو الصفحة. |
| **`k`** | ⬆️ تمرير لأعلى | تمرير خطوتين للأعلى. |
| **`h`** | ⬅️ تنقل لليسار | حركة لليسار بأمان تام. |
| **`l`** | ➡️ تنقل لليمين | حركة لليمين بأمان تام. |
| **`d`** | ⏬ نصف صفحة لأسفل | تمرير سريع بمقدار نصف شاشة. |
| **`u`** | ⏫ نصف صفحة لأعلى | تمرير سريع بمقدار نصف شاشة. |
| **`gg`** | 🔝 قمة الصفحة | انتقال فوري لبداية المستند أو الصفحة (`Ctrl + Home`). |
| **`G`** (`Shift + g`) | 🔚 نهاية الصفحة | انتقال فوري لنهاية المستند أو الصفحة (`Ctrl + End`). |

### 🎯 التلميحات والشبكة:
| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`f`** | 🎯 **تلميحات ونقر أيسر** | تظهر حروف صفراء فوق الأزرار والروابط؛ اكتب الحرف للنقر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **تلميحات ونقر أيمن** | إظهار التلميحات والنقر بزر الماوس الأيمن (Context Menu). |
| **`g`** | 🔢 **شبكة القفز 3x3** | تقسيم الشاشة إلى 9 مربعات والقفز بالرقم من 1 إلى 9. |

### 🌊 التمرير التلقائي الانسيابي (~60 Hz):
| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Space`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** أو **`Numpad +`** | ⚡ **تسريع التمرير** | رفع سرعة التمرير (المستويات من 1 إلى 10). |
| **`-`** أو **`Numpad -`** | 🐌 **تبطئة التمرير** | خفض سرعة التمرير. |
