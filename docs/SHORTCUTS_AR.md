# 📖 دليل الاختصارات الشامل - VimWindows (باللغة العربية)

مرحباً بك في الدليل التفصيلي لاختصارات **VimWindows**. تم تصميم هذه المنظومة لتمنحك تحكماً كاملاً وسريعاً بنظام ويندوز وجميع تطبيقاتك عبر لوحة المفاتيح فقط دون الحاجة للمس الفأرة.

---

## 🎯 بنية الأوضاع (Modes Structure)

يعتمد نظام VimWindows على هيكلية الأوضاع المفصولة (Modal System):

```text
               ┌───────────────────────────────┐
               │    ⚫ INSERT MODE (الكتابة)    │
               └──────────────┬────────────────┘
                              │ اضغط Home أو Ctrl+Win
                              ▼
               ┌───────────────────────────────┐
               │   🟢 NORMAL MODE (الملاحة)    │
               └───────┬──────────────┬────────┘
                       │              │
        اضغط m         │              │ اضغط f
        ▼              │              ▼
┌──────────────────┐   │      ┌──────────────────┐
│ 🖱️ MOUSE MODE    │   │      │ 🎯 HINT MODE     │
│ (تحريك الماوس)   │   │      │ (تلميحات العناصر)│
└──────────────────┘   │      └──────────────────┘
                       │ اضغط g
                       ▼
               ┌──────────────────┐
               │ 🔢 GRID JUMP 3x3 │
               │ (شبكة القفز)     │
               └──────────────────┘
```

---

## 🔘 1. التبديل بين الأوضاع الأساسية

| الاختصار | الوظيفة | الشرح |
| :--- | :--- | :--- |
| **`Home`** | 🟢 **تبديل NORMAL MODE** | ضغطة واحدة للدخول في وضع الملاحة أو الخروج منه. |
| **`Ctrl + Win`** | 🟢 **تبديل بديل** | اختصار بديل لتفعيل أو إيقاف الوضع الطبيعي. |
| **`Esc`** أو **`i`** | ⚫ **وضع الكتابة (INSERT MODE)** | الخروج الفوري من أي وضع والعودة للكتابة العادية. |

---

## 🖱️ 2. وضع الماوس فائق النعومة (MOUSE MODE - `m`)

عند تفعيل `NORMAL MODE`، اضغط على زر **`m`** للدخول في وضع الماوس المستمر:

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`h`** أو **`←`** | ⬅️ **تحريك لليسار** | تحريك مؤشر الماوس لليسار بنعومة وتسارع مستمر. |
| **`j`** أو **`↓`** | ⬇️ **تحريك لأسفل** | تحريك مؤشر الماوس للأسفل بنعومة وتسارع. |
| **`k`** أو **`↑`** | ⬆️ **تحريك لأعلى** | تحريك مؤشر الماوس للأعلى بنعومة وتسارع. |
| **`l`** أو **`→`** | ➡️ **تحريك لليمين** | تحريك مؤشر الماوس لليمين بنعومة وتسارع. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة (Slow/Precision)** | إبطاء حركة الماوس للتحكم الدقيق بالبكسل الواحد. |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو (Fast Turbo)** | مضاعفة سرعة الحركة للتنقل السريع بين الشاشات المتعددة. |
| **`Space`** أو **`Enter`** | 👈 **نقر أيسر (Left Click)** | نقرة ماوس يسارية عادية في موقع المؤشر. |
| **`Shift + Space`** أو **`Shift + Enter`** | 👉 **نقر أيمن (Right Click)** | فتح القائمة السياقية (Context Menu). |
| **`Ctrl + Space`** أو **`,`** | 🔘 **نقر أوسط (Middle Click)** | فتح الروابط في تبويب جديد أو التمرير التلقائي. |
| **`d`** أو **`v`** | ✊ **السحب والإفلات (Drag Mode)** | تثبيت زر الفأرة مضغوطاً لتحديد النصوص وسحب النوافذ، ثم اضغط `d` للإفلات. |
| **`Esc`** أو **`q`** أو **`m`** | ↩️ **خروج من وضع الماوس** | العودة الفورية إلى `NORMAL MODE`. |

---

## 🎯 3. وضع التلميحات الذكي (HINT MODE - `f`)

توليد بطاقات تلميح صفراء فوق كل الأزرار والروابط والحقول التفاعلية داخل النافذة النشطة:

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`f`** | 🎯 **تلميحات ونقر أيسر** | تظهر حروف صفراء فوق العناصر؛ اكتب الحرف للنقر بزر الماوس الأيسر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **تلميحات ونقر أيمن** | إظهار التلميحات والنقر بزر الماوس الأيمن (Context Menu). |
| **`Esc`** أو **`Space`** | ❌ **إلغاء التلميحات** | إخفاء التلميحات والرجوع لـ NORMAL MODE. |

## 🔢 4. شبكة القفز السريع 3x3 (GRID JUMP - `g`)

تقسيم الشاشة إلى 9 مناطق رقمية للقفز الفوري للمؤشر:

```text
┌───────────┬───────────┬───────────┐
│     1     │     2     │     3     │
│ Top-Left  │Top-Center │ Top-Right │
├───────────┼───────────┼───────────┤
│     4     │     5     │     6     │
│ Mid-Left  │  Center   │ Mid-Right │
├───────────┼───────────┼───────────┤
│     7     │     8     │     9     │
│Bottom-Left│Bot-Center │Bot-Right  │
└───────────┴───────────┴───────────┘
```

- اضغط **`g`** لإظهار الشبكة.
- اضغط الرقم من **`1` إلى `9`** للقفز بمؤشر الفأرة فوراً إلى مركز تلك المنطقة.
- اضغط **`gg`** (ضغطتين سريعتين) للانتقال الفوري إلى قمة الصفحة (`Ctrl + Home`).
- اضغط **`G`** (`Shift + g`) للانتقال الفوري إلى نهاية الصفحة (`Ctrl + End`).

## 📜 5. التمرير التلقائي الانسيابي (Smooth Auto-Scroll)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Space`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** أو **`Numpad +`** | ⚡ **تسريع التمرير** | رفع سرعة التمرير (المستويات من 1 إلى 10). |
| **`-`** أو **`Numpad -`** | 🐌 **تبطئة التمرير** | خفض سرعة التمرير حتى المستوى 1 فائق التأني. |
| **`Space`** أو **`Esc`** أو أي زر تنقل | ⏹️ **إيقاف التمرير** | إيقاف التمرير التلقائي فوراً في أي لحظة. |
