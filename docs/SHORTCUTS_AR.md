# 📖 دليل الاختصارات الشامل - VimWindows (باللغة العربية)

مرحباً بك في الدليل التفصيلي لاختصارات **VimWindows**. تم تصميم هذه المنظومة لتمنحك تحكماً كاملاً وسريعاً بنظام ويندوز وجميع تطبيقاتك عبر لوحة المفاتيح فقط دون الحاجة للمس الفأرة.

---

## 🎯 بنية الأوضاع والشارة العلوية

عند تفعيل وضع الملاحة، تظهر شارة مربعة أنيقة وكبيرة في أعلى وسط الشاشة تحتوي على **`NORMAL MODE`** وتظل ثابتة طوال فترة عمل الوضع:

```text
               ┌───────────────────────────────┐
               │    ⚫ INSERT MODE (الكتابة)    │
               └──────────────┬────────────────┘
                              │ اضغط Home أو Ctrl+Win
                              ▼
               ┌───────────────────────────────┐
               │   🟢 NORMAL MODE (الملاحة)    │
               └───────┬──────────────┬────────┘
                       │              │
    الصف الأعلى u/i/o/p│              │ اضغط f
    أو اضغط m          │              │
    ▼                  │              ▼
┌──────────────────┐   │      ┌──────────────────┐
│ 🖱️ MOUSE MOVE    │   │      │ 🎯 HINT MODE     │
│ (تحريك سريع جداً)│   │      │ (تلميحات العناصر)│
└──────────────────┘   │      └──────────────────┘
                       │ اضغط g
                       ▼
               ┌──────────────────┐
               │ 🔢 GRID JUMP 3x3 │
               │ (شبكة القفز)     │
               └──────────────────┘
```

## 🔘 1. التبديل بين الأوضاع الأساسية

| الاختصار | الوظيفة | الشرح |
| :--- | :--- | :--- |
| **`Home`** | 🟢 **تبديل NORMAL MODE** | ضغطة واحدة للدخول في وضع الملاحة أو الخروج منه. |
| **`Ctrl + Win`** | 🟢 **تبديل بديل** | اختصار بديل لتفعيل أو إيقاف الوضع الطبيعي. |
| **`Esc`** | ⚫ **وضع الكتابة (INSERT MODE)** | الخروج الفوري والعودة للكتابة العادية. |

## 🖱️ 2. تحريك الماوس السريع المباشر (الصف الأعلى والأسهم)

يمكنك تحريك مؤشر الماوس مباشرة بسرعة فائقة دون تعطيل اختصارات الملاحة الأصلية (`h`, `j`, `k`, `l`):

| الزر | الاتجاه / الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`u`** أو **`←`** | ⬅️ **يسار** | تحريك مؤشر الماوس لليسار بسرعة فائقة وتسارع فوري. |
| **`i`** أو **`↑`** | ⬆️ **أعلى** | تحريك مؤشر الماوس للأعلى بسرعة فائقة وتسارع فوري. |
| **`o`** أو **`↓`** | ⬇️ **أسفل** | تحريك مؤشر الماوس للأسفل بسرعة فائقة وتسارع فوري. |
| **`p`** أو **`→`** | ➡️ **يمين** | تحريك مؤشر الماوس لليمين بسرعة فائقة وتسارع فوري. |
| **`Shift` (أثناء الحركة)** | 🐌 **وضع الدقة (Precision)** | إبطاء حركة الماوس للتحكم الدقيق بالبكسل الواحد. |
| **`Ctrl` (أثناء الحركة)** | ⚡ **وضع التوربو الخارق** | مضاعفة سرعة حركة الماوس للقفز بين الشاشات المتعددة. |
| **`Enter`** أو **`Space`** | 👈 **نقر أيسر (Left Click)** | نقرة ماوس يسارية عادية في موقع المؤشر. |
| **`Shift + Enter`** | 👉 **نقر أيمن (Right Click)** | فتح القائمة السياقية (Context Menu). |
| **`m`** | 🖱️ **وضع الماوس المستقل** | تفعيل وضع الماوس المخصص (مع أزرار HJKL و Space و d للسحب). |

## 🧭 3. التمرير والملاحة الأصلية بنمط Vimium (محفوظة بالكامل)

جميع اختصارات Vimium الأصلية تعمل بشكل مستقل وثابت:

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`j`** | ⬇️ تمرير لأسفل | تمرير خطوتين للأسفل في المستند أو الصفحة. |
| **`k`** | ⬆️ تمرير لأعلى | تمرير خطوتين للأعلى. |
| **`h`** | ⬅️ تنقل لليسار | حركة لليسار بأمان تام دون الخروج من الوضع. |
| **`l`** | ➡️ تنقل لليمين | حركة لليمين بأمان تام دون الخروج من الوضع. |
| **`d`** | ⏬ نصف صفحة لأسفل | تمرير سريع بمقدار نصف شاشة. |
| **`gg`** | 🔝 قمة الصفحة | انتقال فوري لبداية المستند أو الصفحة (`Ctrl + Home`). |
| **`G`** (`Shift + g`) | 🔚 نهاية الصفحة | انتقال فوري لنهاية المستند أو الصفحة (`Ctrl + End`). |

## 🎯 4. وضع التلميحات الذكي (HINT MODE - `f`)

توليد بطاقات تلميح صفراء فوق كل الأزرار والروابط والحقول التفاعلية داخل النافذة النشطة:

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`f`** | 🎯 **تلميحات ونقر أيسر** | تظهر حروف صفراء فوق العناصر؛ اكتب الحرف للنقر بزر الماوس الأيسر فوراً. |
| **`F`** (`Shift + f`) | 🖱️ **تلميحات ونقر أيمن** | إظهار التلميحات والنقر بزر الماوس الأيمن (Context Menu). |
| **`Esc`** أو **`Space`** | ❌ **إلغاء التلميحات** | إخفاء التلميحات والرجوع لـ NORMAL MODE. |

## 🔢 5. شبكة القفز السريع 3x3 (GRID JUMP - `g`)

تقسيم الشاشة إلى 9 مناطق رقمية للقفز الفوري للمؤشر:

```text
┌───────────┬───────────┬───────────┐
│     1     │     2     │     3     │
│ Top-Left  │Top-Center │ Top-Right │
├───────────┼───────────┼───────────┤
│     4     │     5     │     6     │
│ Mid-Left  │  Center   │ Mid-Right │
├───────────┼───────────┼───────────┤
│     7     │     8     │     9     │
│Bottom-Left│Bot-Center │Bot-Right  │
└───────────┴───────────┴───────────┘
```

- اضغط **`g`** لإظهار الشبكة.
- اضغط الرقم من **`1` إلى `9`** للقفز بمؤشر الفأرة فوراً إلى مركز تلك المنطقة.

## 📜 6. التمرير التلقائي الانسيابي (Smooth Auto-Scroll)

| الزر | الوظيفة | التفاصيل |
| :--- | :--- | :--- |
| **`PgDn`** أو **`Space`** أو **`Ctrl + j`** | ⏬ **تمرير تلقائي لأسفل** | بدء الانزلاق المستمر لأسفل بتردد ~60 هرتز. |
| **`PgUp`** أو **`Ctrl + k`** | ⏫ **تمرير تلقائي لأعلى** | بدء الانزلاق المستمر لأعلى. |
| **`+`** أو **`=`** أو **`Numpad +`** | ⚡ **تسريع التمرير** | رفع سرعة التمرير (المستويات من 1 إلى 10). |
| **`-`** أو **`Numpad -`** | 🐌 **تبطئة التمرير** | خفض سرعة التمرير حتى المستوى 1 فائق التأني. |
| **`Space`** أو **`Esc`** أو أي زر تنقل | ⏹️ **إيقاف التمرير** | إيقاف التمرير التلقائي فوراً في أي لحظة. |
